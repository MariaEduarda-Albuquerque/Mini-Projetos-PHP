# Página de Login com Cookies 

Projeto desenvolvido para fins educacionais, com o objetivo de praticar o uso de *cookies em PHP*.

## Sobre o projeto

Esta é uma *página de login simples*, que permite:

- Salvar dados do usuário em cookies
- Manter os dados mesmo após atualizar a página
- Apagar os cookies quando solicitado

Não há redirecionamento para outras páginas, todo o funcionamento acontece na própria página de login.

## Tecnologias utilizadas

- PHP  
- HTML  
- CSS  

## Funcionamento

- Ao realizar o login, os dados são armazenados em *cookies*
- Ao atualizar a página, os dados permanecem salvos
- Existe a opção de *remover os cookies*, limpando as informações armazenadas
