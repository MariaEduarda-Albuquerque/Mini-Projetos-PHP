# Mini-Projetos PHP
Repositório de mini-projetos desenvolvidos com PHP durante meus estudos na ETEC, organizados por pasta para facilitar navegação e demonstração.
## Sobre o repositório
Este repositório reúne pequenos projetos práticos com PHP, com foco em:
- Praticar lógica de programação no back-end
- Trabalhar com formulários, sessões e cookies
- Manter um portfólio organizado de estudo e evolução
---
## Estrutura do Repositório
| Pasta | Conteúdo |
|---|---|
| `calculadora-imc/` | Calculadora de IMC (Índice de Massa Corporal), com cálculo baseado em peso e altura |
| `formulario-cadastro/` | Formulário de cadastro com envio e processamento de dados via PHP |
| `login-cookies/` | Sistema de login com autenticação e uso de cookies para manter sessão |
| `site-noticias/` | Site de notícias com listagem e exibição de conteúdo dinâmico |
---
## Como executar os programas
**Pré-requisito:** PHP instalado (versão 8 ou superior) ou um ambiente local como XAMPP/WAMP.
```bash
# 1. Clone o repositório
git clone https://github.com/MariaEduarda-Albuquerque/Mini-Projetos-PHP.git
# 2. Acesse a pasta do projeto desejado
cd calculadora-imc
# 3. Inicie o servidor embutido do PHP
php -S localhost:8000
# 4. Acesse no navegador
# http://localhost:8000
```
