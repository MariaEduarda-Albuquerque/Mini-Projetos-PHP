## Sobre o projeto

A Calculadora de IMC permite que o usuário informe:

- Altura
- Peso

Após o envio do formulário, o sistema calcula automaticamente o **IMC (Índice de Massa Corporal)** e exibe o resultado na tela.

Além do valor do IMC, o projeto também mostra:

- Uma **imagem ilustrativa** de acordo com o tipo corporal
- A **classificação do IMC**, como:
  - Magreza
  - Peso normal
  - Sobrepeso
  - Obesidade

## Como executar

**Pré-requisito:** PHP instalado (versão 8 ou superior) ou um ambiente local como XAMPP/WAMP.

```bash
# 1. Clone o repositório
git clone https://github.com/MariaEduarda-Albuquerque/Mini-Projetos-PHP.git

# 2. Acesse a pasta do projeto
cd calculadora-imc

# 3. Inicie o servidor embutido do PHP
php -S localhost:8000

# 4. Acesse no navegador
# http://localhost:8000
```
